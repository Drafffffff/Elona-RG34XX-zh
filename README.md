# Elona foobar RG34XX / NextUI 原生测试版

基于正式版 v0.7.5（292283a4，2020-08-23），为普通 RG34XX 的 H700 / NextUI 原生编译。rg34xx15 重排掌机HUD与对话框：地图格子放大约15%，小地图放大20%；日期、状态、等级、货币按实际字形对齐；日志顶部填充、四行滚动；背包表头在下划线上方，对话框居中并支持正文L/R翻页。rg34xx14 已修复中文长消息造成游戏和按键卡死的问题；中文按字符宽度换行，超长英文单词也能安全拆行。此前 rg34xx13 已完成本移植所带自然语言资源的简体中文翻译，包括菜单、玩法文本、NPC对白、书籍、帮助、全部剧情与随机名称。保留技术命令、专名等明确例外；并非 Elona+。

## 安装

1. 解压 `Elona-RG34XX-NextUI-test.tar.gz`。
2. 挂载 RG34XX 的 NextUI SD 卡。macOS / Linux 上运行：

   `sh elona-rg34xx/install.sh elona-rg34xx /Volumes/你的SD卡`

3. 安全弹出 SD 卡，在 NextUI 的 Ports 分类选择 Elona。

程序目录：`Roms/Ports (PORTS)/.ports/elona-rg34xx`，入口 `Roms/Ports (PORTS)/Elona.sh`。
存档、设置、日志：`.userdata/shared/elona-rg34xx`。升级不会覆盖该目录，建议定期备份。升级会保留程序目录为 `.previous`，再次升级前先归档该旧目录。

退出请在游戏内选择保存退出，出现保存成功提示后再按 A 完成退出并返回 NextUI，不要直接断电。离线测试无法替代真机的音频、性能、睡眠和前端恢复验收。安装脚本仅操作本移植目录。

## 操作和字体

A 确认、B 取消、X 背包、Y 完整行动面板。方向键移动，双方向可斜走。START 游戏菜单，L 等待、R 拾取，L2 目标、R2 射击，SELECT 查看。菜单内方向键短按移动一次、按住连发；L/R 翻页、L2/R2 切换菜单。MENU 中文说明。

rg34xx13 默认显示20像素高的单行按键提示，字号12；游戏场景完整铺满上方720×460，垂直压缩约4.2%，不裁切、不留两侧黑边。按住 MENU 再按 X 收起提示后恢复720×480；MENU查看完整按键表。较大的旧菜单单独适配，保留完整窗口；小窗口最多放大1.35倍。种族/职业字号18并分页详情，天赋每页8项，背包每页10项、字号18、行距26，称号每页9项、字号20，角色摘要主要字段字号20。英文正文最小16像素；密集旧页面仍需实机逐项验收。

属性页按 SELECT 直接继续。天赋页自动选中可选条目，选完一项回到可选列表，分配完全部点数自动进入称号。最终角色摘要按 A 继续，B 重新生成最终信息；展开底栏可查看当前操作提示，MENU 随时打开完整按键说明。rg34xx13 汉化范围及技术保留项见 docs/汉化进度.md；旧存档中已生成的名字与消息历史不会重写。

按住 MENU 再按 R 打开2倍阅读镜，方向键平移，A/B返回。阅读时暂停游戏输入。屏幕键盘会在命名等输入时自动出现，也可 L2+SELECT 手动打开；支持 ASCII 字符、符号、大小写，不含中文输入法。

桌面开发调试键：F8 行动面板，F7 屏幕键盘，F9 阅读镜，F10 操作说明。掌机操作不依赖这些键。所有注册命令均在 Y 面板中，特殊命令仍受游戏上下文及条件限制。音量、亮度等系统按键交由 NextUI 处理，待实机验证。

## 构建

解压源码包后进入 `elona-rg34xx-source`，安装 Docker 并运行：

```sh
docker run --rm -v "$PWD:/src" ghcr.io/loveretro/h700-toolchain@sha256:c9d160c407570a771683e6a471757b44f6e155a7df7d1804c70f901ee3890da3 sh /src/port/prepare-devkit.sh
```

产物是 `build/h700/Elona_foobar`。源包含固定依赖构建输入、目标媒体库、源码、测试和相对正式 tag 的补丁。工具链、系统 ABI、动态库依赖及测试限制见 `docs`。游戏素材从原版 1.22 的 graphic 和 sound 目录取得；源码包不包含这两目录，可从自己的测试包复制。MIDI 需测试包内的 FreePats 配置和音色。

核心通过 ARM64 Linux 环境测试不等于掌机已通过。详细状态以 `docs/测试记录.md` 为准。

升级到rg34xx10后的首次正常启动会自动启用简体中文；正常退出后保留语言设置，以后可在设置中切换。旧存档中已生成的名称可能仍为英文。
