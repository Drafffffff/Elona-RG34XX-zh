# RG34XX 移植测试记录

日期：2026-10-12。目标：普通 RG34XX，NextUI H700，720×480。版本：foobar 正式 v0.7.5 / 292283a4，移植修订 rg34xx4。

## 已验证

- GCC 8.3 交叉编译完整游戏成功，原生 Linux aarch64 ELF，静态 C++ / Lua / Boost，无 Wine / Box64。主程序和携带动态库最高 GLIBC 符号版本为 2.25，ABI 记录见 ABI-report.txt。不能据此独自证明真机运行成功。
- 在 ARM64 Linux Docker 中，使用目标 SDL2 / SDL 扩展库测试：18 个上下文按键映射、斜向按键分量、L2+SELECT 组合键不误发目标指令、失焦释放方向键、完整命令派发、屏幕键盘输入/删除/完成/取消/必填输入、符号字符页、阅读镜和中文帮助渲染通过。
- 目标媒体库测试：PNG 和 JPEG 编解码初始化、中文字体绘制、MIDI 载入和合成至 SDL dummy 音频设备通过。另外模拟了 NextUI 的带空格 Ports 目录，使用 /tmp 音色软链接后 MIDI 合成通过；未验证掌机喇叭实际发声。
- 完整游戏在 ARM64 Linux + Xvfb 中，使用桌面 SDL 核心作可视化测试，媒体扩展与字体来自目标包：选择英文、新建角色、选择种族职业和天赋、外观、角色页、屏幕键盘命名为 123、序章、进入家中地图、NPC 对话、双方向斜走、快捷背包和物品说明通过；最终排序后的 Y 面板可直接进入装备菜单，显示正常。
- 正常保存并退出（保存成功提示后再按确认键退出），生成 save_1/header.json，姓名 123、地点 Your Home；停止测试进程后，以最终 ARM64 引擎重新启动并选择 Continue，成功读取同一角色和地图，位置及物品保留；加载日志无 ERROR / WARN。
- 安装脚本首次安装、升级、保留旧程序目录、保留独立存档目录、重复升级保护通过。
- 默认字号最小 16 逻辑像素；使用 Roboto Condensed 以保留旧表格列宽。最终画面平滑缩至 720×480；2 倍阅读镜显示、平移和退出通过可视检查。仍不是所有复杂旧菜单都重新排版完毕。

开发期间设备离线。未在 RG34XX 上确认 Mali/EGL 驱动初始化、evdev 的实际按键事件、扬声器、帧率、功耗、音量/亮度、睡眠恢复、前端恢复。Docker 完整游戏使用桌面 SDL，独立按键/媒体测试使用目标 SDL，两个结果不可混同为真机通过。交付物属于待实机验收的测试版。
