# Elona foobar → RG34XX / NextUI 原生移植

## 目标与版本决策

目标是普通 RG34XX（H700、720×480、无摇杆）上的 NextUI Ports 原生 Linux ARM64 程序。完全不使用 Wine、Box64 或 Windows 可执行文件。参考已完成的 NextUI 移植工作，独立保存游戏资料，不修改其他游戏或前端。

优先审查更新版本：Elona+ Custom-GX 虽有 HSP 源码，但仍依赖 Windows HSP 运行时及 DLL，当前不能直接原生编译；OpenNefia 和 Elona Power 是未完成的重写，不能作为完整新版 Elona 的交付。根据用户“没有满足的版本就用 foobar”的授权，采用 foobar 正式标签 v0.7.5，提交 292283a4e9f4c784025b3df4404a025d8d00d029（2020-08-23），基础内容来自 Elona 1.22。先前试验的 2021 年归档开发分支虽然能编译，但地图和存档函数已被留空，已弃用；正式标签保留完整实现。不能冒称新版 Elona+。

源码：https://github.com/elonafoobar/elonafoobar
原版资源：https://ylvania.org/file/elona122.zip
候选：https://github.com/JianmengYu/ElonaPlusCustom-GX 、https://github.com/OpenNefia/OpenNefia 、https://github.com/marocato-official/Elona-Power

## 分阶段实施

1. 固定源码及资源版本，核实授权、编译工具链和目标 ABI。将下载、构建中间文件放 work，交付文件独立打包。
2. 使用 NextUI H700 工具链交叉编译。静态链接 C++ 运行库、Boost、Lua；携带必要 SDL 扩展和媒体库。图像编解码器从 SDL_image 2.8.2 编译，支持 PNG/JPEG；MIDI 用 FreePats 软件音源。
3. rg34xx9 改为720×416原生游戏绘制，底部64像素独立中文按键提示。主画面不缩小，较大的旧菜单独立适配、较小窗口最多放大1.35倍。种族/职业详情分页，天赋8项、背包10项、称号9项一页，并同步字号和行距；保留暂停式2倍阅读镜用于密集页面。
4. 接入 ANBERNIC evdev 按键，桌面 SDL joystick 作为回退。八方向走路、菜单短按与延迟连发、上下文快捷键、完整命令面板、自动屏幕键盘都由引擎处理，不依赖外置键盘。所有注册命令通过行动 ID 执行，避免键位冲突。
5. 选择实际可玩的发布标签，避开归档开发快照未完成的 Lua / 数据 / 存档重构。关闭不适合掌机的网络与系统文件选择器。
6. 存档、设置、日志、临时文件迁移至 .userdata/shared/elona-rg34xx。安装使用 staging 与 previous 目录，升级程序不覆盖存档。
7. 在 ARM64 Linux 测试环境验证启动、新建、地图操作、物品菜单、存档退出和重新读取；独立测试按键、图像、字体和 MIDI。设备离线时不能确认实机驱动、性能、扬声器与睡眠恢复。
8. 交付可安装程序、源码和补丁、构建说明、依赖许可、校验清单与验收记录。明天设备上线后再做实机最后一轮验收。

## 全按键布局

|按键|地图|菜单|
|---|---|---|
|方向键|移动；同时按两方向斜走|选择|
|A|确认/交互/楼梯|确认|
|B / START|退出与存档菜单|取消|
|X|快捷背包|切换模式|
|Y|完整行动面板|完整菜单操作面板|
|L|等待|上一页|
|R|拾取|下一页|
|L2|选择目标|上一菜单|
|R2|射击|下一菜单|
|SELECT|查看|鉴定|
|L2 + SELECT|手动屏幕键盘|手动屏幕键盘|
|MENU|中文操作说明|中文操作说明|
|按住 MENU 再按 R|2 倍阅读镜；方向平移，A/B 返回|同左|

文字输入自动打开屏幕键盘：方向选择，A 输入，X 删除，Y 大小写，L/R 字符页，START 完成，B 取消（必填输入不可取消）。支持英文字符和符号，没有中文输入法。输入人物名可用 ASCII。

## 验收标准

- 从 NextUI Ports 启动，画面无黑边裁切、关键选项不遮挡，字体可读。
- 不接键盘完成角色创建；进入地图、斜走、交谈、拾取、物品操作、装备、魔法、目标与射击。
- Y 面板可访问全部注册操作；翻页、数字选择、文本输入可仅用掌机完成。
- 正常保存退出，再进能够读取；替换程序目录后存档仍可读取。
- 正常播放音效与 MIDI；不影响系统音量、亮度及前端恢复；睡眠/唤醒后没有卡键。
- 原生 ARM64 ELF，无 Windows 程序转译；不得把 Docker 模拟测试算成实机通过。

## 已知范围

游戏正文是 foobar 自带英文/日文，新增操作面板和说明为中文；没有完整汉化，不能套用原版 Windows 汉化程序。本次不包含 Elona+ 的新增内容。联网功能和系统原生文件选择器关闭。原始素材随个人测试包提供，不代表取得任意再发布授权。真机结果待设备上线填写。


## rg34xx10 首批正文汉化（2026-10-12）

- 主菜单、存档选择、角色创建的种族/职业与介绍、属性、可选天赋名称与说明、外貌字段和确认步骤。
- 背包操作、常见初始物品、部分材质、装备字段与已知信息、主要属性和技能名称/说明。
- 状态异常、饥饿/疲劳等状态、天气和时段、保存退出提示。
- 序章、开场主要对话、新手教学；教学操作文字按RG34XX控制器改写。
- 正文采用Noto简体中文字体；按UTF-8边界换行；中文物品数量使用“2×名称”，避免英文冠词和复数后缀混入。

Lua资源检查：原8445个文本叶节点均保留；1457个内容发生变化，其中1454个含中文。这个数不包含独立序章文件，也不等于整个游戏的汉化率。未翻译条目保留原英文。

## rg34xx11 底部提示避让（2026-10-12）

默认收起底部常驻提示栏，恢复720×480原生游戏区域。MENU+X 切换提示栏，MENU 打开完整按键帮助。提示展开时完整场景适配720×416，底部64像素独立显示提示；保持宽高比，不裁切、不覆盖。关闭提示后恢复480像素高度。该开关不写入存档，每次启动默认收起。

## rg34xx12 第二批汉化（2026-10-12）

保留独立zh_CN、英文回退与存档安全策略。扩展物品名称、常见描述、附魔、设置、任务日志和活动提示；791个非空基础物品名已覆盖。中文药水/卷轴/魔杖/魔法书名称包含类别后缀，目录查询不再拼接英文of。任务日志中文正文使用32列换行，适应掌机书页和16像素字体。语言包生成器支持Lua长字符串，并跳过用引号表示的表键。

验收关注：物品分类能区分、附魔中的数值和技能参数显示正确、设置说明完整、任务正文不越过右书页、保存读档正常。3,192/8,445条含中文不等于字数完成度，也不代表全部剧情汉化。


## rg34xx13 当前底栏布局

按用户最终要求，提示栏默认显示、固定20像素高，12像素单行字。原生720×480场景完整映射到720×460，垂直压缩约4.2%，铺满提示栏上方，不裁切、不加两侧黑边。MENU+X可收起，恢复720×480；MENU提供完整按键说明。较大的旧菜单继续等比适配。
